# Synthetic Colibri expert file

This model-free G1 fixture reproduces the storage property used by the pinned
Colibri oracle: each expert's packed `gate`, `up`, and `down` weight regions are
adjacent, allowing one positioned read, while their quantization scales occupy
a separate adjacent region. Every region begins on a 16 KiB boundary suitable
for the Apple Silicon shared-memory experiments.

Generate a tiny deterministic artifact:

```sh
bun scripts/experiments/gen-colibri-expert-file.ts /tmp/colibri-experts
```

Pass an optional JSON configuration as the second argument to vary the tiny
layer/expert dimensions. The output is `experts.bin` plus a strict versioned
`manifest.json`. It contains generated byte
patterns only—no model weights or Colibri source—and exists solely to exercise
aligned slab loading, generation-tagged reuse, and MLX/Metal lifetime tests.
