## Inspect the evidence

The [benchmark ledger](/reference/benchmarks/) records results on M1 Max and
M4 Pro, including default batching, context growth, and SSD cache reuse.
Each comparison identifies its model, settings, and machine conditions.
Remaining regressions and unsupported combinations are recorded alongside
successful results.

MLX, mlx-c, mlx-lm, and mlx-optiq provide the runtime foundations and numerical
references. Read [how mlx-bun uses them](/about/comparison/) and the
[correctness contract](/about/correctness/).
